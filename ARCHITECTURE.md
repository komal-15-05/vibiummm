## User Flow

```
1. User Opens App
   ?
2. Page Loads
   ??? Load preferences from localStorage
   ??? Check API configuration status
   ??? Display form
   ?
3. User Fills Form
   ??? Mood (e.g., "Happy")
   ??? Activity (e.g., "Workout")
   ??? Description (optional)
   ??? Language (saved preference)
   ??? Genres (saved preference)
   ??? Explicit filter (saved preference)
   ?
4. User Clicks "Find Music"
   ??? Validate inputs
   ??? Save preferences to localStorage
   ??? Show loading spinner
   ??? Call POST /api/music/suggest
   ?
5. Server Processing
   ??? Receive MusicRequest
   ??? Build query from inputs
   ??? [Optional] Refine with Gemini AI
   ??? Search Spotify API
   ??? Parse results
   ??? Return MusicResponse
   ?
6. Display Results
   ??? Hide loading spinner
   ??? Show success message
   ??? Render track cards
   ?   ??? Album artwork
   ?   ??? Track name
   ?   ??? Artist name
   ?   ??? Spotify link
   ??? Scroll to results
   ?
7. User Interacts
   ??? Hover on card (show play button)
   ??? Click "Open in Spotify"
   ??? Listen on Spotify
```

## API Request/Response Examples

### POST /api/music/suggest

**Request:**
```json
{
  "mood": "Happy",
  "activity": "Workout",
  "description": "Upbeat electronic music",
  "language": "English",
  "genres": "edm, electronic",
  "explicitFilter": false
}
```

**Response:**
```json
{
  "success": true,
  "message": "Found 20 tracks for you!",
  "tracks": [
    {
      "id": "3n3Ppam7vgaVa1iaRUc9Lp",
      "name": "Mr. Brightside",
      "artist": "The Killers",
      "albumName": "Hot Fuss",
      "albumArt": "https://i.scdn.co/image/...",
      "spotifyUrl": "https://open.spotify.com/track/..."
    }
  ]
}
```

## Service Integration

### Spotify Service Flow
```
1. Check if token is cached and valid
   ??? YES: Use cached token
   ??? NO:  Request new token
2. Authenticate with client credentials
3. Cache token (expires_in - 60 seconds)
4. Make API request
5. Parse JSON response
6. Map to TrackInfo models
7. Return results
```

### Gemini Service Flow
```
1. Check if API key is configured
   ??? YES: Call Gemini API
   ??? NO:  Use basic query builder
2. Build prompt from user inputs
3. Send request to Gemini
4. Parse AI response
5. Extract refined query
6. Return query string
7. Fallback to basic if error
```

## Security Flow

```
1. User enters API credentials in appsettings.json
   ?
2. Configuration loaded at startup
   ?
3. Services inject IConfiguration
   ?
4. SpotifyService reads credentials
   ?
5. Encodes to Base64 for Basic Auth
   ?
6. Requests access token
   ?
7. Caches token (never exposed to client)
   ?
8. Uses Bearer token for API calls
   ?
9. Client only receives track data
   ?
10. No credentials sent to browser
```
